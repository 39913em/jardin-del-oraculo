JARDÍN DEL ORÁCULO
POLÍTICA DE PRIVACIDAD

1. DATOS QUE PUEDE GENERAR LA PIEZA

Las funciones interactivas pueden enviar al servicio de Firebase datos necesarios para mantener el estado compartido del jardín y los contenidos que el participante decide introducir, como palabras, frases o versos.

2. ALMACENAMIENTO LOCAL

El sitio puede utilizar almacenamiento local del navegador para recordar determinadas preferencias de la interfaz. No se utiliza para crear un perfil publicitario.

3. SERVICIOS DE TERCEROS

La pieza carga recursos externos, entre ellos módulos de Three.js, Firebase y html2pdf.js. Esos servicios pueden recibir solicitudes técnicas desde tu navegador conforme a sus propias políticas.

4. CONTACTO

Para cuestiones relacionadas con el proyecto: eddmatography@protonmail.ch
